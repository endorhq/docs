Rover provides you with some built-in workflows such as the Software Engineer and the Tech Writer. Rover gives you the ability to create custom workflows to accomodate changes on the existing ones that best fit your needs, or to create complete new ones from scratch for use cases we haven't foreseen.

## The anatomy of a workflow

Workflows are defined in YAML format and follow a pre-defined structure. You can find this structure [in the Workflow YAML File documentation](../../reference/workflow-file).
