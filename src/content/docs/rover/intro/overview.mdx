**Rover is a manager on top of AI coding agents** such as Claude Code, Codex, Gemini, Cursor, and Qwen. Use Rover to **create tasks and assign them to the coding agents** you already use every day.

Once you create a task, you can forget about it until it's completed. Rover will create an isolated environment per task, a separate git branch, and configure the agent to complete the task autonomously in the background. **Everything runs in your system**, under your control. 

**You can create multiple tasks as they run in parallel**. For example, you can use it to:

- **Assign a full task** (like GitHub issue or Jira ticket) so an agent completes it
- Develop a **test suite** for a class while you continue working on a different one
- Write the user documentation for a new feature
- And much more!

Meanwhile, you can continue working on other things or take a break. **Rover ensures that agents are working for you**.

## Getting Started

### Prerequisites
- **Node.js 22** or newer
- **Git**
- **Docker** or **Podman**
- **Supported AI Agent** ([Claude Code](https://docs.anthropic.com/en/docs/claude-code/overview#get-started-in-30-seconds), [Codex](https://github.com/openai/codex?tab=readme-ov-file#installing-and-running-codex-cli), [Gemini](https://github.com/google-gemini/gemini-cli?tab=readme-ov-file#quick-install), [Cursor](https://cursor.com/cli) or [Qwen](https://github.com/QwenLM/qwen-code?tab=readme-ov-file#installation))

## Why Rover?

AI is here to stay, and coding agents are becoming more powerful every day. However, **the experience from different developers and teams is mixed**. Some people show wonderful success cases of coding agents, while others feel frustrated or avoid them as much as possible.

The way people use coding agents is **evolving**. From copy/pasting in ChatGPT to directly integrating them where your code lives. 

In Endor, we went through a similar process. These are the key learnings we found are:

- **The usage of AI agents across the team is uneven**. This creates friction when working on the same codebase.
- **Context switching is costly**. Moving between your code, the coding agent sessions, and back to your code interrupts your flow and focus.
- **Parallelization is key to maximize productivity**. Letting multiple agents work for you while you focus on other tasks is a force multiplier.
- To parallelize work, you need:
  - **Isolation**, so that agents do not interfere with each other
  - A clear **set of steps to get consistent results**

Those learnings led us to build Rover.

### Key Benefits

- **🛠️ Tasks**: Create and manage tasks that AI agents complete on their own
- **🚀 Parallel Execution**: Run multiple AI agents simultaneously on different tasks
- **🔒 Complete Isolation**: Each task runs in its own containerized environment with independent Git worktrees
- **💻 Local Control**: Everything runs on your machine using your existing tools and configurations
- **🤖 Agent Agnostic**: Works with your preferred AI coding agents without requiring new subscriptions
- **👐 Open Source**: Released under Apache 2.0 license
