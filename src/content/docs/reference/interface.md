## Overview 

The Endor Web UI consists of two main components. The inline browser allows you to access websites hosted in the emulated Linux OS. It is pre-configured to load a Welcome page. The sidebar provides access to several tools:

- Editor: Allows you to easily navigate the filesystem of the emulated Linux system.

- Terminal: Allows you to interact with the emulated Linux system through the command line. All Linux shell commands work as expected.

- Folders: Allows the Linux system in the browser access specific folders from your computer so you can run code.

- Debug: Allows you to access in a convenient way various access and error log files for the bundled servers
